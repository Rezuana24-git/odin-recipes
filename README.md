# Odin Recipes

A multi-page recipe website built with HTML as part of The Odin Project's Foundations course.

## Live Demo
[View the site](https://rezuana24-git.github.io/odin-recipes/)

## Features
- Home page with a list of links to all recipes
- Three recipe pages with the same layout
- Each recipe has an image, description, ingredients list, and numbered steps
- "Home" link on every recipe page for easy navigation
- Css style added in all recipe pages and home page

## Built With
- HTML5

## What I Learned
- Structuring pages with headings, paragraphs, lists, images, and links
- Using relative links between pages in different folders
- Style pages in external CSS
- Using Git and GitHub: add, commit, and push

## Project Structure
- `index.html`: the home page
- `recipes/`: the recipe pages
- `imgs/`: the images used on the recipe pages
- `CSS/` : the style used on all pages
